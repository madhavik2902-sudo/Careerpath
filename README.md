# 🎓 CareerPath AI – Student Career Roadmap Generator

## 📌 Project Overview

CareerPath AI is an AI-powered web application designed to help students choose and prepare for their desired career.

The application collects information about the student such as their education, branch, year of study, current skills, interests, skill level, and learning hours. Based on this information, AI generates a personalized career roadmap.

The roadmap helps students understand:

- 🎯 Suitable career direction
- 🛠️ Skills they need to learn
- 📚 Topics to study
- 🧠 Practice areas
- 🎥 YouTube learning resources
- 🚀 Steps to improve their career readiness

The project also provides user registration and login functionality so that students can access their personalized CareerPath AI experience.

---

## ✨ Features

### 🔐 User Authentication
- Create a new account
- Login using username and password
- Passwords are stored as hashed values
- SQLite database is used for user authentication
- Logout functionality

### 👤 Student Profile
Students can provide information such as:

- Name
- Degree
- Branch
- Year of study
- Target career
- Current skill level
- Current skills
- Interests
- Learning hours per week
- Additional information

### 🗺️ Personalized Career Roadmap

CareerPath AI generates a roadmap based on the student's profile.

The roadmap can guide students through:

```text
Student Profile
      ↓
AI Career Analysis
      ↓
Target Career
      ↓
Required Skills
      ↓
Topics to Learn
      ↓
Practice
      ↓
Projects
      ↓
Internship Preparation
      ↓
Career Readiness
